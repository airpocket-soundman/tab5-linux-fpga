# Tab5 Linux × FPGA — プロジェクトガイド

更新日：2026-10-22

Tab5のLinuxからFPGAを使い、データ保存・退避と演算オフロードを研究するプロジェクトです。このリポジトリでは、OSの起動・ビルド環境とFPGA通信ドライバを開発します。

## 目的

### Linuxを研究の土台に

M5Stack Tab5のESP32-P4上でNOMMU Linuxを動かし、LinuxのAPIと既存の開発資産を利用します。MeOSとの速度比較は未実施です。

### FPGAへ明示的にデータを渡す

Tang Primer 20K側の128MB DDR3を、READ / WRITEなどで操作する外部データ領域として利用する構想です。Linuxの空きRAMが128MB増える仕組みではありません。

### 段階ごとに測って進める

1コア構成を起点に、上流修正、低速通信、ドライバとDMA、研究アプリとの接続を順に検証します。

## 次の作業

1. 単体表示テストを基準に、ST7121初期化表とタイミングをLinuxへ移植した成果物を実機で検証する。調査はユーザーの再開指示を受けて進める。
2. USB付近の発熱について、温度と発生条件を記録して原因を調べる。現在は温度未測定で、正常性も未判定。
3. Linuxへ戻した後、Wi-Fiクライアント接続・SSH・Keyboard・設定永続化を確認してL0の証跡をそろえる。
4. 上流との差分を整理し、割り込み・障害処理などの修正を段階的に評価する。
5. キャリア共通仕様を照合し、PARLIOのレジスタ・ピン制御・DMA・Linux対応を調査して最小通信を設計する。
